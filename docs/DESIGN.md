# ConsentDelta visual and interaction baseline

The project-local ui-ux-pro-max engine was invoked before frontend source creation.

Queries: `governance collaboration professional spacious --design-system -p ConsentDelta`; one narrower retry `collaboration SaaS professional spacious --design-system -p ConsentDelta`; focused `keyboard focus modal --domain ux`; separate `routing forms async state --stack react`.

Verified recommendations: Soft UI Evolution is explicitly suited to professional enterprise/SaaS collaboration. The retry's Plus Jakarta Sans typography explicitly fits approachable B2B productivity apps. Calm indigo/success green tokens and improved shallow shadows fit the consent workflow. React results cover controlled forms, async errors and React 19 transitions. UX top result is visible keyboard focus for modal controls, with focus-not-obscured results also relevant.

Unmatched recommendation: both engine queries returned an Operations Landing pattern with metrics/telemetry. That pattern does not fit this user-facing charter application. It is not persisted or presented as verified product evidence. General user-job guidance from the skill and the approved page map determines information architecture; no invented live metrics or testimonials are added.

## Verified tokens to implement

Primary `#6366F1`, on-primary black; secondary `#818CF8`, on-secondary `#0F172A`; CTA `#059669`, on-CTA black; background `#F5F3FF`; foreground/card foreground `#312E81`; card white; muted `#EBEFF9`; muted foreground `#475569`; border `#E0E7FF`; destructive `#DC2626` with white; focus ring `#6366F1`. Measure rendered foreground/background pairs before acceptance. Labels convey status independently of color.

Typography: Plus Jakarta Sans with system fallback, self-hosted and `font-display:swap`. Comfortable 16px body, 1.6 line height, readable text measure. Consistent 8px-based spacing, soft shallow shadows, rounded controls, visible borders. Feedback transition 200ms, no layout-shifting effects; reduced-motion disables transition. Desktop navigation stays consistent; mobile wraps or collapses without horizontal overflow. Meaningful SVG icons use a single Lucide family; decorative icons are hidden from assistive technology.

## Whole-product application

Apply the same tokens and components to all eight routes in the specification. The landing states the value and workflow. Forms group membership/terms and provide local review before signing. Detail screens put exact terms and affected assent first; optional verification lives in native disclosures. Charters provides real canonical search/filter/history; Account handles credits/disconnect; Help explains ambiguity and recovery. No dashboard metrics, backend verdict preview, fixture state, fake balances or system-only controls.

Wallet picker uses a native dialog with a descriptive heading, explicit close, focus containment, Escape dismissal and focus return. Form errors remain inline with linked summary. Buttons disable while pending, async failures give recovery, status announcements do not steal focus. Empty/loading/unavailable/read-error states are honest on each canonical-data route.

Pre-delivery: verify keyboard/labels/focus, 375/768/1024/1440px and landscape layout, contrast, reduced motion, no key/canonical localStorage, full route navigation, build/typecheck and data-unavailable behavior. Phase 3B records observed evidence before this baseline is locked.
